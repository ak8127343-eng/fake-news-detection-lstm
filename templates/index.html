LSTM Model Architecture & Pipeline

How TruthLens AI evaluates news authenticity

01
Raw News Input

Receives unstructured user text from article body or headlines.

↓
02
Keras Tokenizer

Maps words to integer indices based on vocabulary learned during training.

↓
03
Sequence Padding (post, maxlen=300)

Standardizes sequence vector dimensionality to exactly 300 timesteps.

↓
04
Long Short-Term Memory (LSTM)

Gated memory cells capture long-term semantic context and sentence structures.

↓
05
Dense Layer + Sigmoid Activation

Outputs a scalar probability ∈ [0, 1]. Score ≥ 0.50 denotes Real News; < 0.50 denotes Fake News.
